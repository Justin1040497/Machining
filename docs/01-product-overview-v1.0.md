# Machining 产品说明 v1.0

## 产品定位

Machining 是一个本地视频压缩工作台。它把 FFmpeg 的常用视频压缩能力包装成桌面应用，让用户不用写命令也能完成导入、预览、压缩和打开结果文件。

1.0 只面向 macOS Apple Silicon，重点是把视频主链路做稳。

## 目标用户

- 需要压缩课程、录屏、会议视频的普通用户
- 需要快速减小素材体积的视频创作者
- 想使用 FFmpeg 但不想记命令的开发者
- 对上传在线压缩服务有隐私顾虑的用户

## 1.0 解决的问题

- 本地处理，不上传视频
- 内置 FFmpeg，避免要求用户安装 Homebrew
- 提供预览帧，降低压缩参数试错成本
- 串行队列执行，避免多个 FFmpeg 进程抢资源
- 保存任务状态，支持暂停、继续和失败查看

## 1.0 已完成能力

- 文件导入：文件选择和窗口拖拽导入
- 文件分析：通过 FFprobe 获取时长、码率、编码和尺寸等信息
- 视频压缩：默认 H.264，支持 CRF 质量调节
- 格式转换：支持 MP4、MOV、MKV 输出
- 编码选择：支持 H.264、HEVC 和沿用源编码策略
- 预览帧：生成压缩前后对比帧
- 队列执行：支持启动、暂停、继续、取消和删除
- 结果处理：完成后展示输出路径并支持 Finder 打开
- 运行时：内置 macOS arm64 FFmpeg / FFprobe

## 1.0 不解决的问题

- 不提供 Windows / Linux 桌面发布包
- 不提供 DMG、签名和公证成品
- 不处理图片、音频和字幕工作流
- 不提供云端同步、账号和协作
- 不承诺所有异常场景都有友好解释
- 不提供目标体积压缩和批量模板

## 产品状态

1.0 是“可本地使用”的版本，不是完整商业发布版。它适合自己使用、小范围试用和继续迭代。面向公开下载分发前，还需要完成 1.1 的安装包、签名、公证和异常体验打磨。
