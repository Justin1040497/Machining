# 压缩基准计划 v1.1

## 目的

1.0 已经提供可用的 CRF 压缩能力。1.1 需要用真实素材验证默认参数，减少“压缩慢、画质差、体积不降反升”的情况。

## 样本集

建议准备以下视频：

- 手机拍摄 H.264 1080p
- 手机拍摄 HEVC 4K
- 屏幕录制 1080p
- 会议录制
- 短视频平台下载素材
- 已经低码率压缩过的视频
- 高码率相机素材

每个样本记录：

- 文件名
- 时长
- 分辨率
- 源编码
- 源码率
- 源体积
- 是否有音频

## 测试维度

### CRF

- H.264 CRF 20 / 23 / 26 / 28 / 30
- HEVC CRF 24 / 26 / 28 / 30 / 32

### 编码后端

- libx264
- libx265 如果后续启用
- h264_videotoolbox
- hevc_videotoolbox

### 分辨率

- 原始分辨率
- 1080p
- 720p

### 输出格式

- MP4
- MOV
- MKV

## 记录指标

- 输出体积
- 压缩率
- 编码耗时
- 平均速度
- 主观画质评价
- 是否触发失败
- FFmpeg 命令参数

## 目标体积模式调研

1.1 可以评估目标体积压缩：

- 根据目标体积和时长计算目标总码率
- 扣除音频码率得到视频码率
- 对极低目标码率给出警告
- 必要时使用二遍编码

风险：

- 时间成本明显增加
- 极低目标体积会严重损坏画质
- 对已经低码率的视频可能没有收益

## 输出

基准完成后产出：

- 默认 CRF 建议
- 不同素材的推荐策略
- 极限压缩警告阈值
- 是否进入 1.1 的目标体积压缩结论
