# 产品设计 v1.0

## 信息架构

1.0 采用单窗口工作台：

- 左侧：任务列表
- 右侧：任务详情、预览、参数和操作区
- 顶部/浮层：拖拽导入反馈
- 弹窗：完成提示、导入失败、极限压缩确认、重命名

## 任务列表

任务列表负责显示用户当前处理队列。

展示信息：

- 文件名
- 任务状态
- 进度
- 错误状态
- 当前选中状态

支持操作：

- 选择任务
- 右键打开菜单
- 在 Finder 中显示文件
- 重命名任务
- 删除任务

## 任务详情

任务详情展示当前任务的媒体信息和处理配置。

主要内容：

- 源文件路径
- 输出路径或输出目录
- 视频分析信息
- 输出格式
- 视频编码
- 编码后端
- 分辨率
- 压缩质量
- 自定义输出文件名

## 预览设计

预览用于帮助用户判断压缩质量。

规则：

- 只对视频任务生成
- 生成 5 组压缩前后对比帧
- 当前压缩参数变化后，旧预览标记为过期
- 预览失败不阻塞压缩主流程

## 队列交互

任务状态包括：

- pending：待处理
- running：处理中
- paused：已暂停
- completed：已完成
- failed：失败
- missingSource：源文件缺失

核心交互：

- 启动任务时进入 running
- 暂停任务时保留进度和进程上下文
- 继续任务时恢复执行
- 完成后显示完成弹窗
- 失败后保留错误信息，允许用户重新处理

## 拖拽导入

用户把文件拖到窗口时显示顶部反馈文案。松手后应用逐个创建任务。全部成功时显示成功提示；部分失败时显示失败数量，并允许查看失败详情。

## 完成反馈

压缩完成后弹出完成提示：

- 显示输出路径
- 支持打开 Finder
- 支持关闭弹窗继续工作

## 1.0 设计边界

1.0 不做新手引导、营销页、复杂设置页和历史中心。界面首先服务于“导入一个视频并压缩成功”的主路径。
