# 产品路线图

当前项目版本：`v1.1.5`。版本号已随产品更名重置。

## 已完成阶段

### 核心压缩主链路

- 本地视频导入。
- FFprobe 媒体分析。
- 预览帧生成。
- H.264 / HEVC 压缩。
- 输出格式和分辨率配置。
- 任务队列、暂停、继续、删除和重命名。
- macOS arm64 内置 FFmpeg / FFprobe。
- 核心服务测试。

### Windows 和 GPU 编码基础支持

- Windows x64 运行时打包基础支持。
- macOS / Windows GPU 编码加速能力检测。
- 自动编码器后端选择。
- 跨平台 FFmpeg 定位和运行时资源配置。

### 主界面体验重构

- 更轻便的工作台界面。
- 视频缩略图生成。
- 任务配置窗口和窗口顶部样式优化。
- 文档目录初步整理。

### 推荐方案、目标体积和代码整理

- 智能压缩预设。
- 目标体积压缩。
- 压缩结果预估。
- 主界面模块拆分。
- 任务配置弹窗重构。
- 跨平台打开文件所在位置。
- 默认 CPU / GPU 自动选择修复。

### 应用设置和发布准备

- 增加应用设置入口。
- 构建应用设置弹窗。
- 支持默认输出目录配置。
- 支持自定义 FFmpeg / FFprobe 路径配置。
- 支持高级选项、原始日志等应用级开关。
- 设置变更后写入本地设置表，并在后续任务中生效。
- 将目标体积模式调整为比例滑杆。
- 补充缺失源文件重新指定流程。
- 完善 GPLv3+、第三方声明、源码获取说明和发布包法律资料复制。
- 增加 macOS DMG 打包入口和发布验证脚本。
- 增加首页关于入口、GitHub 和 Gitee 项目入口。

### 分层重构和工作台整理

- Application 层补充 Use Cases，减少表现层直接拼装业务流程。
- Infrastructure 层拆分 provider、服务实现和持久化兼容映射。
- features/workbench 拆分页面布局、弹窗、覆盖层、配置代码和可复用组件。
- 压缩模式收敛为推荐方案和自定义目标体积，历史持久化值通过兼容层处理。
- 统一工作台弹窗风格，并优化右上角通知动画。

### 媒体处理基础扩展

- 将任务主配置从视频专用配置泛化为 `MediaTaskConfig`，并加入视频、图片、音频分类型配置。
- Drift schema 升级到 14，新增通用任务配置 JSON 和图片分析字段，同时保留旧视频列兼容历史任务。
- 文件导入、FFprobe 分析和 FFmpeg 命令规划支持视频、图片、音频三类媒体。
- 图片任务使用步骤型进度和源图缩略图；音频任务禁用视频流输出。
- 图片任务开放格式、分辨率、质量和元数据保留配置，后台按格式推导图片编码参数。
- 音频任务开放格式、码率、采样率和声道配置，后台按格式推导音频编码参数。
- 工作台导入、空态、关于弹窗和完成弹窗文案收敛为通用媒体处理表述。

### 工作台主题和交互体验

- `default_media_config_json` 读写兼容已启用。
- 应用设置弹窗已开放默认视频、图片、音频处理配置。
- 保留旧视频默认字段的读取和保存兼容。
- 工作台颜色、按钮、弹窗、通知、状态标签、进度条和表单控件统一接入主题 token。
- 接入 `flutter_screenutil`，控制桌面文本和控件尺寸。
- 支持浅色主题和深色主题。
- 顶部栏提供主题图标按钮，可在浅色和深色之间取反切换。
- 主题偏好写入应用设置，并在应用首帧前读取，避免先浅色再闪到深色。
- 任务列表支持拖拽排序，并持久化任务顺序。
- 设置弹窗顶部媒体类型切换复用任务配置卡分段组件。

## 下一阶段规划

### 默认媒体配置验收和发布验证

目标：完成通用默认媒体配置从开发可用到发布可靠的最后验证。

- 补齐图片和音频端到端手动验收。
- 验证 macOS / Windows 发布包中图片、音频、专有音频输入和关键编码器链路。
- 检查工作台、任务列表、弹窗、预览区和通知浮层在两套主题下的发布前视觉一致性。
- 后续如需要，可扩展 `AppThemeMode.system` 支持跟随系统外观。

### 后台压缩功能

目标：让用户在压缩任务执行期间可以最小化或切换窗口，任务继续稳定运行。

- 支持窗口最小化后继续压缩。
- 明确关闭窗口、退出应用和后台运行之间的行为边界。
- 增加后台任务状态提示。
- 避免后台压缩时任务进度、完成提示和失败状态丢失。
- 补充暂停、继续、取消和异常退出后的恢复规则。

### FFmpeg 许可证协议规范化

目标：让内置 FFmpeg / FFprobe 的构建、分发和许可证说明具备可发布的规范性。

- 已整理 `LICENSE`、`legal/NOTICE.md` 和 `legal/` 下的第三方许可证说明。
- 已补充 FFmpeg / x264 版本、构建参数和源码获取说明。
- 已明确 GPL 路线下的发布包要求。
- 已规范 Release 包内许可证文件放置位置。
- 已更新 `docs/reference/` 中的 FFmpeg 许可与分发参考文档。
