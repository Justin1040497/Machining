# 需求说明 v1.0

## 版本目标

1.0 的目标是交付一个可运行、可构建、可使用内置 FFmpeg 的 macOS 视频压缩工作台。

验收标准：

- 用户可以导入视频并看到任务
- 用户可以分析视频并生成预览
- 用户可以压缩视频并得到输出文件
- 用户可以暂停、继续、删除和重命名任务
- Release app 可以使用包内 FFmpeg，不依赖 Homebrew
- `flutter analyze` 和 `flutter test` 通过

## 功能需求

### 文件导入

- 支持通过文件选择导入视频
- 支持拖拽文件到窗口导入
- 支持一次导入多个文件
- 不支持的文件需要给出导入失败提示

### 媒体分析

- 使用 FFprobe 分析视频文件
- 保存分析结果到任务
- 源文件缺失时把任务标记为缺失状态
- 分析失败时保留错误信息

### 压缩配置

- 输出格式：MP4、MOV、MKV
- 视频编码：H.264、HEVC、沿用源编码
- 编码后端：自动、软件、硬件
- 分辨率：保持原始或使用预设
- 输出目录：默认使用源文件目录，可手动指定
- 输出文件名：支持自定义，冲突时自动追加数字后缀
- 压缩质量：通过 CRF 控制普通压缩质量

### 预览

- 对视频任务生成 5 组预览点
- 每组包含原始帧和压缩后帧
- 参数变化后预览结果应失效
- 预览失败时任务仍可继续压缩

### 队列

- 串行执行 FFmpeg 任务
- 支持启动单个任务
- 支持暂停当前任务
- 支持继续暂停任务
- 支持取消任务
- 支持当前任务和目标任务切换
- 后台观测 FFmpeg 输出并更新进度

### 完成与错误

- 完成后保存输出路径
- 完成后弹窗提示用户
- 用户可以在 Finder 中打开输出文件
- 失败任务保存错误消息
- FFmpeg 不可用时任务失败并提示

## 非功能需求

- 所有媒体处理在本机完成
- 默认不依赖用户安装的 FFmpeg
- FFmpeg 日志落盘，便于定位问题
- 数据使用本地 SQLite 保存
- UI 保持单窗口工作台形态
- 不在 1.0 引入账号、网络服务或后台守护进程
