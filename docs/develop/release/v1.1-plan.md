# 开发计划 v1.1

## 背景

1.0 已经完成视频压缩主链路。1.1 不再补做“核心压缩能力”，而是围绕发布、异常体验和真实素材验证进行打磨。

## 优先级 P0

### 发布合规

- 增加 `LICENSE`
- 增加 `THIRD_PARTY_NOTICES`
- 整理 FFmpeg / x264 许可证和源码说明
- 确认 app 包内许可证放置位置

### macOS 分发

- 制作 DMG
- 配置代码签名
- 配置 Apple 公证
- 在另一台 Mac 上验证安装和启动
- 验证内置 FFmpeg 在下载位置运行

### 错误体验

- 源文件缺失时提供重新定位入口
- 输出目录无权限时给出明确提示
- 磁盘空间不足时提前阻止启动
- FFmpeg 启动失败时显示可操作建议

## 优先级 P1

### 任务历史

- 增加历史视图
- 区分当前队列和历史记录
- 支持清理已完成任务
- 支持打开历史输出文件

### 压缩目标

- 调研目标体积压缩策略
- 设计目标体积输入
- 增加安全边界，避免过度压缩
- 增加测试覆盖

### 基准测试

- 准备真实视频样本集
- 记录源编码、码率、时长和体积
- 对比 CRF、码率和硬件编码结果
- 形成推荐默认参数

## 优先级 P2

- 批量参数模板
- 音频码率设置
- 输出目录规则
- 更多格式边界测试
- UI 文案细化

## 验收标准

- 能生成可安装 DMG
- 安装后 app 可以正常使用内置 FFmpeg
- 另一台 Apple Silicon Mac 验证通过
- 许可证和第三方说明齐全
- 新增错误场景有测试或手动验证记录
- `flutter analyze` 通过
- `flutter test` 通过
