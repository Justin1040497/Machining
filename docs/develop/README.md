# 开发文档入口

## 文档目的

这个目录保存和开发、测试、发布验证有关的说明。

它不负责记录产品定位，也不负责沉淀历史过程。产品范围看 `docs/product/`，历史记录看 `docs/archive/`。

## 目录职责

```text
docs/develop/
  release/   发布计划、签名、公证、安装包和版本收尾
  testing/   测试计划、压缩基准和手动验证说明
```

## 当前文档

- `release/v1.1-plan.md`：v1.1 发布打磨计划。
- `testing/test-plan-v1.0.md`：v1.0 自动化测试和手动验证范围。
- `testing/compression-benchmark-plan-v1.1.md`：v1.1 真实素材压缩基准计划。

## 给 AI 的使用说明

涉及实现前，先读 `docs/architecture/README.md`。涉及验收和发布，再读本目录。
