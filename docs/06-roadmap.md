# Roadmap

## v1.0.0 当前版本

状态：已完成本地可用版本。

范围：

- macOS Apple Silicon
- 本地视频导入
- FFprobe 分析
- 预览帧生成
- H.264 / HEVC 压缩
- 格式输出
- 任务队列
- 暂停、继续、删除、重命名
- 完成提示和 Finder 打开
- 内置 FFmpeg / FFprobe
- 自动化测试通过
- Release app 构建通过

## v1.1.0 发布打磨

目标：从“自己可用”推进到“小范围分发可用”。

计划内容：

- DMG 安装包
- 代码签名和 Apple 公证
- `LICENSE` 和第三方许可证整理
- Release 包内许可证目录
- 首次启动和 FFmpeg 状态提示优化
- 磁盘空间、权限、源文件丢失等错误场景优化
- 任务历史独立视图
- 目标体积压缩模式调研和第一版实现
- 更多真实素材压缩基准

## v1.2.0 参数和批量体验

目标：提升批量处理效率。

候选内容：

- 压缩预设管理
- 批量统一设置
- 音频码率配置
- 输出目录规则
- 覆盖/跳过/自动重命名策略
- 任务导入去重

## v1.3.0 媒体能力扩展

目标：从视频压缩工具扩展为更完整的本地媒体工具。

候选内容：

- 音频转码
- 音频抽取
- 简单裁剪
- 图片压缩评估
- 字幕保留策略

## v2.0.0 跨平台评估

目标：评估 Windows / Linux 发布。

前置条件：

- macOS 版本稳定
- FFmpeg 运行时分发策略清晰
- 自动化测试覆盖核心用例
- 安装包和更新策略明确
