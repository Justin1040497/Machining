# v1.2.0 输出配置和文件名模板

## 版本事实

FrameLean 在 v1.2.0 开发期将“默认导出文件名”从固定选项改为可编辑模板。默认模板为：

```text
{source}-{date}-{action}
```

对应长期决策见 `docs/decisions/260613-output-template-settings-application.md`。

## 模板边界

- 支持 `{source}`、`{date}`、`{version}`、`{action}`、`{codec}`、`{encoder}`。
- `{source}` 始终来自源文件路径的 basename，不使用任务展示名。
- `{version}` 表示处理版本；首次处理为 `v1`，同源同类型同目的重复导入时递增为 `v2`、`v3`，重试同一个任务保持原版本号。
- `{codec}` 表示编码格式或媒体输出格式；视频输出为 `h264` 或 `h265`。
- `{encoder}` 表示视频编码器后端；输出为 `auto`、`x264`、`x265`、`videotoolbox`、`nvenc`、`qsv` 或 `amf`。
- 数字之间的 `x / X` 自动规范化为 `×`，例如 `1920x1080`。
- `x{codec}` 和 `x{encoder}` 会移除多余前缀，避免生成 `xh264` 或 `xx264`。
- 目标文件已存在或与源文件同名时，导出路径自动追加 `（1）`、`（2）`，不再使用 `-1`、`-2`。

## 设置生效边界

- 视频、图片、音频任务配置保存后作为后续导入任务的默认值。
- 输出配置保存后，会立即刷新未开始、失败和已取消任务的输出目录与输出文件名。
- 运行中或暂停中的任务保留执行快照；重来或下一次处理时读取最新输出配置。
- 临时通知最多展示两行摘要，通知中心记录展示完整内容。

## 验证范围

- 模板规范化、变量渲染、`{version}` 递增和不重复 `x` 前缀。
- 设置页模板输入、常用模板菜单和变量说明。
- 输出配置保存刷新非运行任务，重来时读取最新输出配置。
- FFmpeg 输出路径构造继续按源文件路径生成默认名，并使用中文括号冲突递增规则。
