# v1.2.0 媒体任务默认值、保持原始和元数据配置

## 版本事实

FrameLean 在 v1.2.0 开发期统一视频、图片和音频的任务默认值与任务详情配置语义。默认任务配置只作为后续导入任务的初始值，不自动覆盖已有任务；任务详情弹窗保存后只更新当前任务。

长期决策见 `docs/decisions/260613-media-task-source-format-and-metadata.md`。

## 设置页默认值

- 图片、视频、音频默认输出格式独立成行，样式复用默认导出地址的“标题 + 复选框 + 输入控件”结构。
- 勾选“默认保持源文件格式”后，下方固定格式选择框禁用；取消勾选后恢复固定格式选择。
- 图片默认质量独立成行，复用任务详情中的质量滑杆组件，但设置页不展示底部刻度。
- 视频默认模式中的“推荐方案选项”和“自定义目标体积”决定下一次打开视频任务弹窗时默认展示哪个模式。

## 任务详情保持原始

- 任务详情不再显示单独的“保持源文件格式”开关行。
- 格式下拉直接显示真实源格式加 `（保持原始）`，例如 `MP4（保持原始）`、`MOV（保持原始）`。
- 分辨率下拉直接显示真实源分辨率加 `（保持原始）`，例如 `3840 × 2160（保持原始）`。
- 保持原始选项来自导入分析阶段的源格式和源分辨率；底层仍保存真实格式值和 `keepOriginalOutputFormat` 布尔状态。
- 如果源格式或源分辨率已经作为保持原始选项出现，下拉列表不再重复显示相同普通选项。

## 元数据配置

- 图片任务继续保留现有元数据开关，默认不保留。
- 视频和音频任务新增元数据开关，默认保留以兼容旧任务和常见用户预期。
- 用户关闭视频或音频元数据保留后，FFmpeg 命令显式剥离输出元数据。

## HDR 相关交互

- “保持 HDR”只在源视频确认为 HDR 时显示。
- 开启“保持 HDR”后，当前任务编码切换到 HEVC，并禁用编码选择框。
- 开启“保持 HDR”后，当前任务自动回到推荐方案并默认清晰优先；自定义目标体积、微信发送和体积优先不可选。
- 关闭“保持 HDR”后，恢复开启前用户选择的编码和后端。
- 当前版本不承诺保留 Dolby Vision 动态元数据；带 HDR10 兼容层的 Dolby Vision 只按 HDR10 基础层处理。

## 验证范围

- 设置页默认输出格式、保持源格式复选框和图片质量滑杆布局。
- 图片 / 视频 / 音频任务详情弹窗打开、保存和保持原始选项展示。
- MOV、MP4、PNG 等源格式显示 `（保持原始）` 后缀且不重复展示普通同值选项。
- 视频 / 音频元数据保留和剥离命令。
- HDR 开启状态下的目标体积和高压缩预设禁用交互。
- 非视频任务打开详情时不读取视频专属配置。
