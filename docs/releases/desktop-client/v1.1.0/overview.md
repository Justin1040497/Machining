# v1.1.0 版本概览

## 当前事实

`v1.1.0` 聚焦 Windows 兼容、FFmpeg 输出参数、进程控制和发布包稳定性。这个版本让 Windows 暂停 / 继续、打开文件位置、发布 zip 布局和 FFmpeg 参数规划更可靠。
