# v1.2.1 Release

## 版本摘要

v1.2.1（构建号 `1.2.1+8`）集中完善桌面媒体处理可靠性和工作台效率：新增任务夹批量工作流、受控并行、隐藏 partial 输出保护、更新入口、通知与快捷键设置，并重制了不会阻挡前景交互的工作台背景引导。主要发布平台仍为 macOS Universal 2 和 Windows x64。

## 主要变更

- 更新体验提供工作台状态、轻量通知和完整版本日志，并支持 GitHub、Gitee 与备用下载入口；公开发布默认由系统浏览器打开下载页。
- 任务夹成为本地持久化实体，支持批量导入自动建夹、夹级配置、夹内排序、拖入 / 移出、重命名、聚合日志和批量执行。
- 执行队列支持受控并行和手动任务抢占；输出先写入同目录隐藏 partial，通过校验后再发布最终文件。
- 视频输出扩展到受约束的 MP4、MOV、MKV、WebM、AVI 容器 / 编码矩阵；透明视频自动使用 MOV + ProRes 4444 保留 alpha。
- 设置新增通知投递策略、快捷键重映射、并行任务上限、文件夹扫描深度和关闭到后台行为。
- 工作台新增低透明度动态背景引导，按可用空间协调任务操作、全部开始和添加按钮提示，同时保留空白背景双击导入。

## 重要修复

- 修复分析、调度和资源租约之间可能形成的等待或补位问题，统一导入、分析、执行和恢复状态语义。
- 修复输出目录、权限、重名冲突、运行中 partial 被删除和最终发布失败未及时暴露的问题。
- 修复图片或音频压缩输出无效仍被标记成功，以及透明视频 alpha 被常规编码策略破坏的问题。
- 修复 FFprobe / FFmpeg 超时或无有效进度时进程继续占用资源，以及硬件编码会话失效缺少降级重试的问题。
- 修复多任务工作台两组背景引导交叉、文本压线、箭身贴住箭头边缘和窗口变化后布局不稳定的问题。

## 兼容性与已知问题

- 可从 v1.2.0 升级；本地 Drift 数据库会迁移到 schema 30。降级到旧版本前应备份并恢复对应数据库。
- macOS 使用 Universal 2 DMG；Windows 使用当前用户安装器，并提供可选 x64 便携 ZIP。
- package 自更新、COS ticket、Windows updater helper、macOS 私有 DMG 缓存和 Sparkle appcast 仍作为兼容能力保留，但不是当前公开发布的默认路径；重新启用前需单独完成真实包验签、下载和安装回归。
- 显式指定图片输出格式时，无效输出会失败并提示原因；队列中的“失败后询问是否允许改格式”交互尚未提供。
