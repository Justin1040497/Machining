# 视频压缩工作台

## 所属版本

`v1.0.0`

## 当前事实

FrameLean 在 `v1.0.0` 建立了以视频压缩为主的工作台。用户可以拖拽或选择导入视频，查看分析信息，配置推荐方案或自定义目标体积，再交给本地 FFmpeg 队列执行。

## 设计方式

- 使用统一工作台承载任务列表、任务配置、预览信息和底部操作。
- 视频任务支持输出格式、视频编码、编码器后端、分辨率、输出目录和输出文件名配置。
- 压缩模式包括推荐方案和自定义目标体积。
- 完成后显示输出路径，并提供打开文件所在位置入口。

## 为什么这样设计

FrameLean 的目标用户需要快速压缩录屏、课程、会议视频或内容素材。工作台式界面能让导入、配置、执行和查看结果停留在同一上下文里，比多页面流程更轻。

## 设计收益

- 压缩主链路清晰，用户不需要理解 FFmpeg 参数。
- 任务配置和队列状态都能在同一个页面看到。
- 后续图片、音频能力可以复用工作台和任务模型。

## 边界

- 这个版本以视频为主，不包含图片和音频处理。
- 不包含云端压缩、账号体系或批量目录递归导入。
